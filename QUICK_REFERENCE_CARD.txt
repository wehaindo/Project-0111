┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔧 FIRST TIME SETUP                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

   Step 1: Create Database
     • Open http://localhost:8069
     • Database Name: odoo13_pos
     • Email: admin@example.com
     • Password: admin
     • Demo Data: ✅ Yes (recommended)
     • Click "Create database"
     • Wait 2-3 minutes

   Step 2: Install POS Module
     • Apps → Install "Point of Sale"

   Step 3: Install POS Hybrid Sync
     • Apps → Update Apps List
     • Search: "pos hybrid" or "weha_pos_self_sync"
     • Click Install

   Step 4: Configure
     • Point of Sale → Configuration → Point of Sale
     • Go to "Hybrid Sync" tab
     • Enable all options
     • Save

   Step 5: Open POS
     • Point of Sale → Dashboard → New Session
     • Enjoy offline-first POS! 🎉

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🆘 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

   Problem: Port 8069 already in use
   Solution: netstat -ano | findstr :8069
            Then kill process or change port

   Problem: Docker not running
   Solution: Start Docker Desktop, wait for ready

   Problem: Module not found
   Solution: docker-compose restart odoo

   Problem: Can't access Odoo
   Solution: docker-compose logs odoo
            Wait 60 seconds after start


┌──────────────────────────────────────────────────────────────────────────────┐
│ 🛠️ USEFUL COMMANDS                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

   View container status:
     docker-compose ps

   Access Odoo shell:
     docker exec -it odoo13_app odoo shell -d odoo13_pos

   Access database:
     docker exec -it odoo13_postgres psql -U odoo

   Update module:
     docker exec -it odoo13_app odoo -d odoo13_pos -u weha_pos_self_sync

   Backup database:
     docker exec -t odoo13_postgres pg_dump -U odoo odoo13_pos > backup.sql

   View real-time logs:
     docker-compose logs -f odoo
